Ещё в целом не понравилось — надо сделать "режим" чтения более изолированным — сейчас в нём слишком много информации помимо самого текста, часть можно вынести перед тем, как человек читать начнёт, как у Эпл Букс собственно. ## 0. Ground rules (all builders)

- **Product truth stays**: daily issue (00:00 MSK), blind reading (author sealed until the end) + author guess, reactions (local + optional Redis API), Pabchik's note and facts after the ending, archive, personal shelf, reader settings, sharing (riddle link `?z=1`, plain link, VK, quote card `/rasskaz/[slug]/karta?q=`), PWA, transfer key. Public-domain content only; never invent claims, counts or testimonials.
- **Apple Books, not a costume**: system canvas (white / black), colour only from covers, glass only on the control layer (tab bar, floating circle buttons, sheets, menus, toasts). **Never glass on content** (no frosted cards, no glass behind story text). No glass inside glass: inside a sheet use flat fills `var(--fill-2)`.
- **Minimal**: labels 1–3 words, at most one sentence of secondary text per block. No kicker/eyebrow labels above headings, no uppercase letter-spaced mono labels, no section numbers, no emoji, no gradient text, no cards nested in cards, no bento grids, no coloured `border-left` callouts. Russian UI copy, «ёлочки», «—», «ё» where it belongs, address the reader as «вы».
- **Type**: large titles `.t-large` (serif 34, ui-serif→Literata), section titles `.t-title2` (serif 22), UI text = system-ui (17/15/13). Book titles in serif. Use only the text styles in globals.css plus local sizes that sit on that ramp (34, 28, 22, 20, 17, 15, 13, 11). Digits that line up: `.num`.
- **Shared building blocks (do not edit them; if you need a change, say so in your final report)**:
  - `src/app/globals.css` (tokens, `.glass`, `.glass-strong`, `.glass-tint`, `.press`, `.t-*`, `.seal-*`, `.blind-only`, `.reveal-only`, `.edge-top`, view-transition classes `book`, `open-book`, `page-in`, `page-out`).
  - `src/components/ui/Book.tsx` (cover object: `<Book cover title issue width depth sheen sealed priority />`), `ui/GlassButton.tsx` (44px glass circle / capsule; `tint` for cover-coloured fields), `ui/PageHeader.tsx` (large title + grey second line + actions), `ui/Sheet.tsx` (inset glass sheet on `<dialog>`, drag to dismiss), `ui/SealedAuthor.tsx` (needs an ancestor `data-seal={slug}`), `ui/icons.ts` (Phosphor; add nothing else — if an icon is missing, report it), `TabBar.tsx`, `GlassLens.tsx`, `BlindStyle.tsx`, `ClientEffects.tsx`, `app/layout.tsx`.
  - More shared UI (also read-only for builders): `ui/Countdown.tsx` (`<Countdown target={epochMs} />`, refreshes the route once the issue opens), `ui/Hud.tsx` (`showHud(text, icon?, sub?)` — icons: "check" | "link" | "bookmark" | "quote" | "goal"; host already mounted in layout), `ui/PillMenu.tsx` (Apple pill-stack menu: `<PillMenu label trigger={(p) => <GlassButton {...p} …/>} items={[{label, icon, onSelect, primary?, destructive?, hint?}]} placement="down-end|up-end|down-start" />`), `ui/Segmented.tsx` (`<Segmented value options={[{value,label}]} onChange label size />`), `ui/ThemeTiles.tsx` (the six reader themes, wired to prefs; `READER_THEMES`), `ui/Goal.tsx` (`GoalRing`, `GoalGauge`, `WeekDots`), `lib/share.ts` (`shareOrCopy(url, title, text?)`).
  - `src/lib/shelf.ts` (store v2: read, opened, progress, percent, reactions, guesses, want, quotes, log, goal, profile, prefs, onboarded; actions markOpened, markRead, saveProgress(slug, paragraph, percent), setReaction, setGuess, toggleWant, addQuote, removeQuote, logReading(seconds), setGoal, setProfile, setPrefs, completeOnboarding, dismissInstallHint, resetShelf, exportKey, importKey, getDeviceId, useShelf, useHydrated, applyPrefs), `lib/stats.ts` (todaySeconds, streak, week, readThisYear, totalMinutes, guessScore, achievements, WEEK_LETTERS), `lib/cover.ts` (`coverVars(colors)` → `--cover-bg/-dark/-light/-tint/-base`), `lib/haptics.ts` (`tick()`), `lib/date.ts` (+ `mskDayKey`, `addDays`, `weekdayIndex`), `lib/content.ts` (stories now carry `cover`; `getTomorrowTeaser` returns blurred cover data only), `lib/types.ts`, `lib/cards.ts` (`toCard` includes `hook` and `cover`).
- **Blind reading**: any author/year shown for a story must be wrapped as `<span data-seal={slug}><SealedAuthor name=… year=… /></span>` (or put `data-seal` on the card root). Content that must stay hidden until the reveal uses `.reveal-only`; content only for the sealed state uses `.blind-only`. Story pages put the visible title in an element with `data-seal-title` (the tab-title mask reads it).
- **Hydration**: personal state (read, progress, want…) only exists in the browser. Render server markup that is correct for a first-time visitor, then use `useShelf()` + `useHydrated()` in small client components. Never read `localStorage` during render.
- **Motion**: transform/opacity/clip only, `var(--snappy)` for UI, `var(--bouncy)` only for the book of the day. Never animate `backdrop-filter`. Respect `prefers-reduced-motion`. Shared element: wrap the cover in `<ViewTransition name={`book-${slug}`} share="book" default="none">` (import `ViewTransition` from "react") on every surface that shows a book which the user can tap to open its sheet, and in the sheet; the reader uses `share="open-book"` on its full-screen paper layer (see §3). - **Performance**: ≤ 2 glass surfaces visible while scrolling (the tab bar counts), blur radius is fixed in globals, no `will-change` at rest, images via `<Book>` (lazy by default; `priority` only for the first viewport hero).
- **Accessibility**: every control has an accessible name in Russian, 44px touch targets, visible focus (global ring), contrast AA on cover-coloured fields (white text on `--cover-bg` is pre-checked ≥ 4.5:1), sheets are `<dialog>`, tab order sane, `aria-current` on navigation.

## 1. Information architecture

Floating glass tab bar: **Сегодня** `/` · **Архив** `/arhiv` · **Полка** `/polka` + search circle **Поиск** `/poisk`. Hidden in the reader (`/rasskaz/*`) and on the full-page book (`/kniga/*`).

| Route | What |
|---|---|
| `/` | Today: the book of the day as an object + continue/goal/week. First visit → onboarding overlay. |
| `/kniga/[slug]` | Book page (full page, SEO, shareable). The same content opens as a **sheet** over the current screen via the intercepting route `app/@modal/(.)kniga/[slug]/page.tsx` — this is the "pop-up before reading". |
| `/rasskaz/[slug]` | Reader: text only. After the last line → the **finish** sequence (guess → reveal → reaction → Pabchik's note → share → tomorrow / next). |
| `/arhiv` | Archive: all published issues — covers grid by month, calendar view, list view; filter by mood/length/unread. |
| `/poisk` | Search: field + browse by mood (cover-coloured tiles) + authors. |
| `/polka` | My shelf: reading now, want to read, finished, liked, quotes; stats header; gear → settings sheet. |
| `/profil` | Profile: name/avatar, reading goals (daily minutes ring + week + streak + this year), achievements, settings, transfer key, about. Reached from the avatar circle on Today and from Полка. |
| `/avtor/[slug]`, `/avtory`, `/o-proekte` | Keep as plain SEO pages restyled to the new system (large title, grouped lists). |

Every cover tap anywhere → `/kniga/[slug]` (sheet). «Читать» in the sheet → `/rasskaz/[slug]` (open-book transition). Tomorrow's slot → no link, shows countdown.
