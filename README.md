# FantPub 2.0 — рассказ на каждый день

Веб-приложение «книга дня»: каждый день открывается один короткий рассказ — классика из общественного достояния в новых переводах. Книгу нужно «распечатать» (сломать сургучную печать), автор спрятан до финала, после текста — реакция, записка домового Пабчика и полка, которая растёт сама.

- `web/` — приложение (Next.js 16, App Router, CSS Modules, без WebGL).
- `web/content/stories/*.md` — рассказы (frontmatter + текст), `web/content/authors.json` — авторы.
- `research/` — продуктовые исследования: критика вводных, конкуренты, SEO, Mobbin, бренд, маскот, шрифты, синтетические интервью и опросы, стек.
- `tools/` — генерация картинок через Codex CLI и headless-скриншоты для QA.

## Как добавить рассказ

1. Создать `web/content/stories/<slug>.md` по образцу соседних файлов. Поле `issue` — номер выпуска; дата выхода считается от `LAUNCH_DATE` в `web/src/lib/date.ts` (выпуск № 1 = дата запуска, каждый следующий +1 день, смена в 00:00 МСК).
2. Если автора ещё нет — добавить его в `authors.json`.
3. Закоммитить: Vercel пересоберёт сайт. Будущие выпуски до своей даты отдают 404 и не попадают в sitemap.

## Локально

```bash
cd web && npm install && npm run dev
```

## Переменные окружения (Vercel)

| Переменная | Зачем |
|---|---|
| `NEXT_PUBLIC_SITE_URL` | канонический адрес сайта (OG, sitemap) |
| `KV_REST_API_URL`, `KV_REST_API_TOKEN` | Upstash Redis для общих счётчиков реакций; без них реакции сохраняются только у читателя |
| `CRON_SECRET` | защита cron-маршрута ежедневной смены выпуска |
